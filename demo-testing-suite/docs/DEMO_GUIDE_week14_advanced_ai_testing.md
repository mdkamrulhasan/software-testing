## AI-Assisted Testing

**Files:** `ai_generated/build_prompt.py`, `suite_from_code.py`,
`suite_from_spec.py`, `evaluate.py`

```bash
python ai_generated/build_prompt.py from_code | head -20   # the task text
pytest ai_generated/suite_from_code.py -q                  # 2 failed, 39 passed  <- correct shop
SHOP_COUPONS=per_unit pytest ai_generated/suite_from_code.py -q   # 41 passed <- buggy shop
pytest ai_generated/suite_from_spec.py -q                  # 46 passed
SHOP_COUPONS=per_unit pytest ai_generated/suite_from_spec.py -q   # 3 failed
python ai_generated/evaluate.py ai_generated/suite_from_code.py ai_generated/suite_from_spec.py --quick
```

Before running the first suite, ask the class to predict: will tests an
AI wrote from the code pass on the correct shop? Then show the two
failing parameter rows (`suite_from_code.py:129`, `:144-146`).

**Live variant (recommended):** paste the `from_code` prompt into the
class's AI assistant, save the reply as `ai_generated/live.py`, and run
`python ai_generated/evaluate.py ai_generated/live.py --quick` (about
5 s; drop `--quick` for the mutants, about 25 s in all). Results differ
from run to run and from assistant to assistant, which is itself a
point. The instructor edition's note explains that the committed suites
were generated by the same assistant that prepared the course material.

### Reviewing AI-written tests

Open `suite_from_spec.py` at `test_flat5_needs_an_order_of_at_least_ten_dollars`
and ask the class to say what the parametrization evaluates to.
